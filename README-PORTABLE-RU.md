# MarCat Portable — быстрый старт

MarCat — локальный маркетинговый планировщик для инди-игр. Portable-версия не требует установки: достаточно положить файл `MarCat-<версия>-portable.exe` в удобную папку и запустить его.

## Первый запуск

1. Запустите portable-файл. Если Windows SmartScreen предупредит о неизвестном издателе, проверьте имя и контрольную сумму полученного файла, затем разрешите запуск. Сборка пока не подписана сертификатом.
2. Выберите русский язык в приветственном окне.
3. Создайте проект игры: укажите название, короткий ключ проекта и, при наличии, ссылку на страницу Steam.
4. Откройте «Фестивали»: в чистой поставке уже есть общий календарь событий с датами. Выберите подходящие события для своего проекта.
5. Импортируйте CSV из Steamworks в разделе «Аналитика» или добавляйте данные вручную.

## Данные и приватность

- В поставке нет чужих проектов, ключей API, подключённых аккаунтов, заметок или истории работы.
- На первом запуске MarCat создаёт новую локальную базу в `%APPDATA%\MarCat`. У каждого пользователя она своя и не отправляется разработчику автоматически.
- Общий каталог фестивалей содержит только названия, типы и даты. Проверяйте актуальность дат и условия участия на официальных страницах организаторов.
- Для переноса или резервной копии используйте раздел «Настройки → Резервные копии».

## Необязательные возможности

MarCat работает без API-ключей. Ключи и токены нужны только для тех AI-функций и внешних источников, которые пользователь подключает сам в «Настройках». Не передавайте свою базу или файлы секретов третьим лицам.

Для массового поиска каналов откройте «Инфлюенсеры → YouTube Discovery». Встроенная подсказка проведёт через включение YouTube Data API v3, безопасное сохранение ключа и создание проектного профиля с играми-референсами или гранями тематики. Найденные каналы сначала попадают в отдельный список кандидатов; в боевую CRM они переходят только после явного подтверждения.

История изменений находится в `CHANGELOG.md` рядом с portable-файлом.
